# German ABC

German uses the same 26 letters as English, plus four extra characters. The hard part is that several familiar letters sound different from what you'd expect.

## The 4 extra characters

| Letter | Sound | Examples |
|---|---|---|
| **ä** | like the "e" in "bed" | Bär, Mädchen |
| **ö** | say "e" (as in "bed") with lips rounded for "o" | schön, können |
| **ü** | say "ee" with lips rounded for "oo" | müde, über |
| **ß** (Eszett) | a sharp "s" (as in "see"), used after long vowels and diphthongs | Straße, heiß |

- In all-caps text, ß is usually written as **SS** (STRASSE). A capital **ẞ** exists but is rare.
- Swiss German doesn't use ß at all. It always writes **ss**.

## Letters that sound different from English

| Letter        | Sound                                                      | Example                 |
| ------------- | ---------------------------------------------------------- | ----------------------- |
| **w**         | English "v"                                                | Wasser ("VAH-ser")      |
| **v**         | usually English "f"; "v" in loanwords                      | Vater ("FAH-ter"), Vase |
| **z**         | "ts"                                                       | Zeit ("tsite")          |
| **j**         | English "y"                                                | ja ("yah")              |
| **s**         | before a vowel: English "z"                                | Sonne ("ZON-ne")        |
| **r**         | back of the throat; almost vowel-like at the end of a word | rot, Lehrer             |
| **y**         | mostly in loanwords; often like "ü"                        | Typ                     |
| **b / d / g** | at the end of a word: "p / t / k"                          | Kalb, Hund, Tag         |

## Important letter combinations

| Combination | Sound                                          | Examples                |
| ----------- | ---------------------------------------------- | ----------------------- |
| **ch**      | after a, o, u, au: a throaty scrape            | Buch, Nacht             |
| **ch**      | elsewhere: a soft hiss, like the "h" in "huge" | ich, Milch              |
| **-ig**     | at the end of a word: like "ich"               | König, richtig          |
| **sch**     | English "sh"                                   | Schule                  |
| **sp / st** | at the start of a word or stem: "shp / sht"    | Sport, Stein, verstehen |
| **ei**      | "eye"                                          | nein                    |
| **ie**      | long "ee"                                      | Liebe                   |
| **eu / äu** | "oy"                                           | neu, Häuser             |
| **au**      | "ow" as in "cow"                               | Haus                    |
| **pf**      | both sounds together                           | Pferd                   |
| **qu**      | "kv"                                           | Quelle                  |

> **ei vs. ie** is the classic trap. Say the *second* letter's English name: e**i** → "eye", i**e** → "ee".

## Vowel length matters

- **Long** vowel: followed by one consonant, an "h", or a doubled vowel (Ofen, Kohl, Staat).
- **Short** vowel: followed by two or more consonants (offen, Stadt).

Length can change the meaning, so notice it early:

| Long | Short |
|---|---|
| Ofen (oven) | offen (open) |
| bieten (to offer) | bitten (to ask) |
| Staat (state) | Stadt (city) |

## Practical tips

- **Spelling is consistent.** Unlike English, once u know the rules u can read any word  correctly.
- **Nouns are always capitalized** (der Tisch, die Liebe), which makes them easy to spot in a sentence.
- **Can't type ä, ö, ü, ß?** Use **ae, oe, ue, ss**. You'll see this in emails and usernames.
- **Learn to spell your name aloud in German.** You'll be asked at appointments and on the phone. Watch the letter names that differ from English: **V** = "Fau", **W** = "Weh", **J** = "Jott", **Y** = "Ypsilon", **Z** = "Zett".

## Common mistake

Don't pronounce ü and ö as plain "u" and "o". The umlaut changes the word:

- schon (already) vs. schön (beautiful)
- Mutter (mother) vs. Mütter (mothers)
