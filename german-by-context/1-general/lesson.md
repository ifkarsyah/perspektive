# Learning German by using Chunking Phrases

## Context

Native speakers produce language largely from memorized chunks (“Ich hätte gern ein...”, “Könnten Sie mir...?”, “Ich würde gern...”), not from assembling rules word by word.

Learn each frame as one chunk, then swap the slot. Say every variation out loud.

## The only case table you need at first

Most slots are accusative (the thing you want, need, or look for). Only masculine changes.

| | m | f | n | pl |
|---|---|---|---|---|
| Nominative (subject) | der / ein | die / eine | das / ein | die / (no article) |
| **Accusative** (object) | **den / einen** | die / eine | das / ein | die / (no article) |
| Dative (mit, bei, seit, in + location) | dem / einem | der / einer | dem / einem | den + n / (no article) |

Rule of thumb: if the frame takes a thing as its object, masculine becomes **einen / den**. Everything else stays the same as nominative.

---

## 1. Ich hätte gern ___ (I would like ___)

Polite ordering and requesting. The slot is accusative.

| Gender | Variation |
|---|---|
| m | Ich hätte gern **einen** Kaffee. / **einen** Termin. / **einen** Tisch für zwei. |
| f | Ich hätte gern **eine** Suppe. / **eine** Auskunft. / **eine** Quittung. |
| n | Ich hätte gern **ein** Wasser. / **ein** Zimmer. / **ein** Brötchen. |
| pl | Ich hätte gern **zwei** Bier. / **Informationen** zur Anmeldung. |

Close cousin: **Ich möchte ___** (same slot, slightly more direct). "Ich möchte einen Termin."

## 2. Ich möchte ___ + Infinitiv (I would like to ___)

The infinitive goes to the **end**.

- Ich möchte ein Konto **eröffnen**.
- Ich möchte einen Termin **vereinbaren**.
- Ich möchte mich **anmelden**.
- Ich möchte das **bezahlen**.
- Ich möchte etwas **bestellen**.
- Ich möchte meinen Vertrag **kündigen**.

## 3. Könnten Sie ___? (Could you ___?)

Polite request. Verb at the end again.

- Könnten Sie das bitte **wiederholen**?
- Könnten Sie **langsamer sprechen**?
- Könnten Sie mir **helfen**?
- Könnten Sie mir das **erklären**?
- Könnten Sie das **aufschreiben**?
- Könnten Sie mir den Weg **zeigen**?

Informal version: **Kannst du ___?**

## 4. Ich suche ___ (I am looking for ___)

| Gender | Variation |
|---|---|
| m | Ich suche **einen** Supermarkt. / **einen** Arzt. / **einen** Deutschkurs. |
| f | Ich suche **eine** Wohnung. / **eine** Apotheke. / **die** Ausländerbehörde. |
| n | Ich suche **ein** WG-Zimmer. / **das** Bürgeramt. / **ein** Café. |
| pl | Ich suche **günstige** Wohnungen. |

## 5. Wo ist ___? / Wo finde ich ___?

`Wo ist` + nominative (no change). `Wo finde ich` + accusative.

- Wo ist **der** Bahnhof? / **die** Toilette? / **das** Bürgeramt?
- Wo finde ich **einen** Geldautomaten? / **eine** Bushaltestelle? / **ein** Taxi?

## 6. Ich brauche ___ (I need ___)

- Ich brauche **einen** Nachweis. / **einen** Termin.
- Ich brauche **eine** Bescheinigung. / **eine** Meldebescheinigung. / **eine** SIM-Karte.
- Ich brauche **ein** Formular. / **ein** Konto.
- Ich brauche **Hilfe**. / **Zeit**. / **mehr Informationen**.

## 7. Ich habe ___ (I have ___)

Negation uses **kein** (follows the same endings as **ein**): keinen / keine / kein.

- Ich habe **einen** Termin um zehn Uhr.
- Ich habe **eine** Frage. / **ein** Problem.
- Ich habe **keinen** Vertrag. / **keine** Ahnung. / **kein** Bargeld.

## 8. Gibt es ___? (Is there ___?)

Always accusative.

- Gibt es hier **einen** Aufzug?
- Gibt es hier in der Nähe **eine** Apotheke?
- Gibt es **ein** Problem?
- Gibt es **freie Termine**?

## 9. Modal verbs: muss / kann / will / darf / soll

Conjugated modal in position 2, infinitive at the **end**.

- Ich **muss** mich anmelden.
- Ich **kann** leider nicht kommen.
- **Kann** ich mit Karte bezahlen?
- **Darf** ich hier sitzen?
- Ich **will** nach Berlin umziehen.
- Wir **müssen** das Formular heute abgeben.

## 10. Ich bin ___ / Ich wohne ___ / Ich lerne ___ (introducing yourself)

- Ich bin **Dateningenieur**. / Ich bin **aus Indonesien**. / Ich bin **neu in Berlin**.
- Ich wohne **in Berlin**. / **seit einem Monat** in Tokio.
- Ich lerne **seit drei Monaten** Deutsch.
- Ich arbeite **bei** einer Firma. / **als** Ingenieur.

Note: **seit** + dative (einem Monat, drei Monaten). The plural dative adds **-n**.

## 11. mit + dative (transport, company, tools)

| Gender | Variation |
|---|---|
| m | Ich fahre mit **dem** Bus. |
| f | Ich fahre mit **der** S-Bahn. / **der** U-Bahn. |
| n | Ich fahre mit **dem** Zug. / **dem** Fahrrad. |
| pl | Ich spreche mit **den** Kollegen. |

Also: Ich zahle mit **der** Karte. / mit **dem** Handy.

## 12. Wie viel kostet ___? / Was kostet ___?

- Wie viel kostet **das**?
- Was kostet **ein** Monatsticket?
- Wie viel kostet **die** Miete?
- Was kosten **die** Nebenkosten? (plural verb: kosten)

## 13. When you do not understand

- Ich verstehe **das** nicht.
- Ich verstehe **das Wort** ___ nicht.
- Was bedeutet ___?
- Wie sagt man ___ auf Deutsch?
- Entschuldigung, mein Deutsch ist noch nicht so gut.

## 14. Subordinate clauses: verb goes to the END

After **ob, wo, wann, wie, weil, dass**, the conjugated verb moves to the end.

- Ich weiß nicht, **wo** das Bürgeramt **ist**.
- Können Sie mir sagen, **wann** der Termin **ist**?
- Ich weiß nicht, **ob** ich einen Termin **brauche**.
- Ich komme später, **weil** die S-Bahn Verspätung **hat**.
- Ich glaube, **dass** das Formular **fehlt**.

## 15. Perfekt: Ich habe ___ gemacht / Ich bin ___ gegangen

Most verbs use **haben**. Verbs of movement or change of state use **sein**. The participle goes to the **end**.

- Ich **habe** gearbeitet. / eingekauft. / angerufen.
- Ich **habe** eine Wohnung gefunden.
- Ich **habe** den Vertrag unterschrieben.
- Ich **bin** umgezogen. / angekommen. / gefahren.

---

## Practice method

1. Pick one frame per day.
2. Fill the slot with **one noun of each gender** (m, f, n, pl) and say all four aloud.
3. After about 10 frames, read a short grammar summary of the accusative and dative. It will label what you already recognize.
4. When you notice a repeated mistake (for example **ein Kaffee** instead of **einen Kaffee**), go back and fix that one rule explicitly.

## Suggested priority for a Berlin move

Frames 2, 3, 4, 6, 8, 9, and 13 first (bureaucracy, apartment, daily survival). Then 1, 5, 7, 12. Then 14 and 15 once the basics feel automatic.
