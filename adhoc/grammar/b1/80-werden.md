# werden

## The idea in one sentence

**werden** has three jobs, and what comes with it tells you which one: **become**, the **future**, or the **passive**.

## Compare with English

| Comes with...   | Job     | German                     | English                |
| --------------- | ------- | -------------------------- | ---------------------- |
| adjective/noun  | become  | Es **wird** kalt.          | It's getting cold.     |
| infinitive      | future  | Ich **werde** dir **helfen**. | I will help you.    |
| past participle | passive | Das Auto **wird repariert**. | The car is being repaired. |

## Step 1: The forms

The du and er/sie/es forms are irregular:

| Who       | werden  |
| --------- | ------- |
| ich       | werde   |
| du        | **wirst** |
| er/sie/es | **wird** |
| wir       | werden  |
| ihr       | werdet  |
| sie/Sie   | werden  |

## Step 2: Job 1: become

- Es **wird** spät. (It's getting late.)
- Ich **werde** nächste Woche 30. (I'm turning 30 next week.)
- Sie **wird** Ärztin. (She's becoming a doctor.)
- Mir **wird** schlecht. (I'm starting to feel sick.)

## Step 3: Job 2: the future

### Usually, you don't need it

In conversation, just use the present tense with a time word:

- Ich **komme morgen**. (I'll come tomorrow.)
- Wir **fahren nächstes Jahr** nach Japan. (We're going to Japan next year.)

### When people do use it

Build it like a modal verb, with the infinitive at the end. People use it mainly for two things:

**Promises and strong intentions:**

- Ich **werde** dir **helfen**. (I will help you.)
- Das **werde** ich nie **vergessen**. (I'll never forget that.)

**Guesses**, often with **wohl** or **bestimmt**:

- Er **wird** wohl krank **sein**. (He's probably sick.)
- Das **wird** bestimmt schön. (That's bound to be nice.)

Remember from [modal verbs](../a1/50-modal-verbs/51-modal-verbs-forms.md): **Ich will** means "I want to", not "I will". "I will" is **Ich werde**.

## Step 4: Job 3: the passive

The passive is for when the **action** matters more than who does it.

Build it with **werden + past participle at the end**:

| Active (who does it)          | Passive (what happens)       |
| ----------------------------- | ---------------------------- |
| Man repariert das Auto.       | Das Auto **wird repariert**. |
| Man baut hier ein Haus.       | Hier **wird** ein Haus **gebaut**. |
| Man öffnet die Tür um 8 Uhr.  | Die Tür **wird** um 8 Uhr **geöffnet**. |

If you need to say who did it, use **von + dative**. In speech you'll rarely need this:

- Das Essen **wird von** meiner Mutter **gekocht**.

## Step 5: The passive with modal verbs

This is very common at work and in offices. The modal takes seat 2, and **participle + werden** goes at the end:

- Das **muss** heute **gemacht werden**. (That has to be done today.)
- Das **kann repariert werden**. (That can be repaired.)
- Hier **darf** nicht **geraucht werden**. (Smoking isn't allowed here.)

## Step 6: In speech, man is often easier

[man](60-lassen-man-word-order/62-man.md) can often replace the passive, and it's simpler to build:

| Passive                       | With man                    |
| ----------------------------- | --------------------------- |
| Das muss gemacht werden.      | Das muss man machen.        |
| Das kann repariert werden.    | Das kann man reparieren.    |
| Hier darf nicht geraucht werden. | Hier darf man nicht rauchen. |

For the passive in the past, see [recognize only](90-recognize-only.md). When speaking, use man or an active sentence instead.

## Phrases to memorize

| German            | English                 |
| ----------------- | ----------------------- |
| Das wird schon!   | It'll be fine!          |
| Wird gemacht!     | Will do!                |
| Es wird spät.     | It's getting late.      |
| Mir wird schlecht. | I'm starting to feel sick. |
| Das wird schwer.  | That's going to be hard. |

## In conversation

> **Nora:** Ist der Bericht fertig?
> **Lukas:** Noch nicht, aber er **wird** heute **geschickt**.
> **Nora:** Das **muss** bis drei Uhr **gemacht werden**.
> **Lukas:** **Wird gemacht!**
> **Nora:** Danke. Ich habe ein bisschen Angst, dass es zu spät **wird**.
> **Lukas:** Keine Sorge, **das wird schon**.

## Common mistakes

| ❌ Wrong                  | ✅ Right                   | Why                                |
| ------------------------ | -------------------------- | ---------------------------------- |
| Du werdest 30.           | Du wirst 30.               | du → wirst                         |
| Er werdet Arzt.          | Er wird Arzt.              | er → wird                          |
| Ich will dir helfen. (= I will) | Ich werde dir helfen. | will = want to                  |
| Ich werde helfen dir.    | Ich werde dir helfen.      | infinitive at the end              |
| Das Auto wird reparieren. | Das Auto wird repariert.  | passive → participle               |
| Das muss machen werden.  | Das muss gemacht werden.   | participle + werden                |
| Das muss gemacht wird.   | Das muss gemacht werden.   | after a modal → infinitive werden  |

## Summary

- **werden + adjective/noun** = become.
- **werden + infinitive** = future. Use it for promises and guesses.
- **werden + participle** = passive.
- Modal passive: **muss gemacht werden**.
- For plans, just use the present: **Ich komme morgen.**
- Memorize: **Das wird schon! Wird gemacht!**
