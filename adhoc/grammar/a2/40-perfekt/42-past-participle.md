# Past Participle (Partizip II)

## The idea in one sentence

The past participle is the "-ed / -en" form of the verb (like "played", "eaten"), and in German it usually looks like **ge- + stem + -t** or **ge- + stem + -en**.

## Compare with English

English has regular and irregular participles:

- **Regular**: play → play**ed**, work → work**ed** (just add -ed)
- **Irregular**: eat → eat**en**, go → **gone**, drink → dr**u**nk (vowel changes, -en)

German is exactly the same idea:

- **Regular**: **ge**spiel**t**, **ge**arbeit**et** (ge- + -t)
- **Irregular**: **ge**gess**en**, **ge**gang**en**, **ge**trunk**en** (ge- + -en, vowel often changes)

Even the vowel changes are sometimes similar: drink → dr**u**nk, trinken → getr**u**nken!

## Type 1: Regular verbs → ge- + stem + -t

Take the stem (infinitive minus -en), put **ge-** in front and **-t** at the end:

| Infinitive | Stem   | Participle         | English  |
| ---------- | ------ | ------------------ | -------- |
| machen     | mach   | **ge**mach**t**    | done/made |
| spielen    | spiel  | **ge**spiel**t**   | played   |
| kaufen     | kauf   | **ge**kauf**t**    | bought   |
| lernen     | lern   | **ge**lern**t**    | learned  |
| wohnen     | wohn   | **ge**wohn**t**    | lived    |
| kochen     | koch   | **ge**koch**t**    | cooked   |

If the stem ends in **-t** or **-d**, add **-et** (easier to say):

- arbeiten → **ge**arbeit**et**
- warten → **ge**wart**et**

## Type 2: Irregular verbs → ge- + (changed) stem + -en

These you have to **memorize**, just like English "eat → eaten, go → gone". Good news: they're mostly the same verbs that are irregular in English too!

| Infinitive | Participle     | English     |
| ---------- | -------------- | ----------- |
| essen      | ge**gess**en   | eaten       |
| trinken    | ge**trunk**en  | drunk       |
| sehen      | ge**seh**en    | seen        |
| lesen      | ge**les**en    | read        |
| schreiben  | ge**schrieb**en | written    |
| schlafen   | ge**schlaf**en | slept       |
| finden     | ge**fund**en   | found       |
| nehmen     | ge**nomm**en   | taken       |
| geben      | ge**geb**en    | given       |
| sprechen   | ge**sproch**en | spoken      |
| treffen    | ge**troff**en  | met         |
| gehen      | ge**gang**en   | gone        |
| kommen     | ge**komm**en   | come        |
| fahren     | ge**fahr**en   | driven      |
| fliegen    | ge**flog**en   | flown       |
| bleiben    | ge**blieb**en  | stayed      |
| sein       | ge**wes**en    | been        |
| werden     | ge**word**en   | become      |

### Tip: notice the vowel patterns

Some verbs follow the same vowel change, so learn them in groups:

- **ei → ie**: schreiben → geschr**ie**ben, bleiben → gebl**ie**ben
- **i → u**: trinken → getr**u**nken, finden → gef**u**nden, singen → ges**u**ngen
- **e → o**: sprechen → gespr**o**chen, nehmen → gen**o**mmen, treffen → getr**o**ffen

## Type 3: Mixed verbs → ge- + changed stem + -t

A small group: the vowel changes like irregular verbs, but the ending is **-t** like regular verbs.

| Infinitive | Participle    | English     |
| ---------- | ------------- | ----------- |
| bringen    | ge**brach**t  | brought     |
| denken     | ge**dach**t   | thought     |
| wissen     | ge**wuss**t   | known       |
| kennen     | ge**kann**t   | known       |

Compare English: bring → br**ought**, think → th**ought**. Same weirdness!

And: haben → **gehabt**.

## Type 4: Separable verbs → ge- goes in the middle

For [separable verbs](../../a1/60-separable-verbs.md), the **ge-** goes **between the prefix and the verb**:

| Infinitive  | Prefix + ge + participle | Result          |
| ----------- | ------------------------ | --------------- |
| einkaufen   | ein + **ge** + kauft     | ein**ge**kauft  |
| aufstehen   | auf + **ge** + standen   | auf**ge**standen |
| anrufen     | an + **ge** + rufen      | an**ge**rufen   |
| fernsehen   | fern + **ge** + sehen    | fern**ge**sehen |
| mitkommen   | mit + **ge** + kommen    | mit**ge**kommen |
| aufräumen   | auf + **ge** + räumt     | auf**ge**räumt  |

- Ich habe gestern **eingekauft**. (I went shopping yesterday.)
- Hast du mich **angerufen**? (Did you call me?)

## Type 5: No ge- at all

### Verbs with inseparable prefixes

be-, emp-, ent-, er-, ge-, ver-, zer- → **no ge-** added:

| Infinitive | Participle    |
| ---------- | ------------- |
| besuchen   | besucht       |
| bezahlen   | bezahlt       |
| verstehen  | verstanden    |
| vergessen  | vergessen     |
| bekommen   | bekommen      |
| erklären   | erklärt       |

(Why? Because ge- + ver- would be too many prefixes. "geverstanden" sounds awful.)

### Verbs ending in -ieren

| Infinitive    | Participle    |
| ------------- | ------------- |
| studieren     | studiert      |
| telefonieren  | telefoniert   |
| fotografieren | fotografiert  |
| reparieren    | repariert     |

## How to learn the irregular ones

1. Learn them **in the sentence**, not alone: "Ich habe Pizza gegessen."
2. Learn them **with haben/sein**: "ist gegangen", "hat gegessen".
3. Start with the 20 most common (the table above). That covers most daily conversation.

## Common mistakes

| ❌ Wrong          | ✅ Right         | Why                                 |
| ---------------- | --------------- | ----------------------------------- |
| geesst           | gegessen        | essen is irregular                  |
| gegeht           | gegangen        | gehen is irregular                  |
| geeinkauft       | eingekauft      | separable: ge- in the middle        |
| gebesucht        | besucht         | be- → no ge-                        |
| gestudiert       | studiert        | -ieren → no ge-                     |
| gearbeitt        | gearbeitet      | stem ends in -t → add -et           |

## Summary

- **Regular**: ge- + stem + **-t** (gemacht).
- **Irregular**: ge- + stem + **-en**, vowel may change (gegessen, getrunken). Memorize.
- **Mixed**: ge- + changed stem + -t (gebracht, gedacht).
- **Separable**: ge- in the middle (eingekauft).
- **No ge-**: be-/ver-/er-... verbs and -ieren verbs (besucht, studiert).
