# Two-Way Prepositions

## What is this about?

So far you have:
- prepositions that **always** take accusative (für, ohne...)
- prepositions that **always** take dative (mit, zu, bei...)

Now a third group that can take **either one**. They're called **two-way prepositions** (Wechselpräpositionen).

**an, auf, hinter, in, neben, über, unter, vor, zwischen**

## The idea in one sentence

With the nine two-way prepositions: **movement to a place (wohin?) → accusative**, **location (wo?) → dative**.

## How do you choose?

It depends on whether something is **moving to a place** or **staying in a place**:

| Question                     | Situation          | Case            |
| ---------------------------- | ------------------ | --------------- |
| **wohin?** (where to?)       | movement, change of place | **accusative** |
| **wo?** (where?)             | location, no change | **dative**     |

## Compare with English

English sometimes shows this difference with two words:

- I go **into** the room. (movement) → Ich gehe **in das** Zimmer. (accusative)
- I am **in** the room. (location) → Ich bin **in dem** Zimmer. (dative)

"into" vs "in", "onto" vs "on". German uses the same preposition but changes the case instead.

## Picture it

Imagine a ball and a box:

- 🏀 ➡️ 📦 The ball **flies into** the box → **wohin?** → accusative: **in den** Karton
- 🏀📦 The ball **is in** the box → **wo?** → dative: **in dem** (im) Karton

## Why it matters

These prepositions are everywhere when you talk about places: putting things somewhere, saying where things are, giving directions, describing your apartment.

## Step 1: The nine prepositions

| Preposition | Meaning              |
| ----------- | -------------------- |
| **in**      | in, into             |
| **an**      | at, on (a vertical surface), by (water) |
| **auf**     | on (top of)          |
| **über**    | above, over          |
| **unter**   | under, below         |
| **vor**     | in front of          |
| **hinter**  | behind               |
| **neben**   | next to              |
| **zwischen** | between             |

They're all about **position in space**. That's why they can describe both "going to a spot" and "being at a spot".

## Step 2: The rule with examples

| wohin? → accusative (movement)          | wo? → dative (location)                  |
| --------------------------------------- | ---------------------------------------- |
| Ich gehe **in den** Park.               | Ich bin **im** Park.                     |
| Ich lege das Buch **auf den** Tisch.    | Das Buch liegt **auf dem** Tisch.        |
| Ich hänge das Bild **an die** Wand.     | Das Bild hängt **an der** Wand.          |
| Die Katze läuft **unter das** Bett.     | Die Katze schläft **unter dem** Bett.    |
| Ich stelle das Auto **vor das** Haus.   | Das Auto steht **vor dem** Haus.         |

## Step 3: How to decide

Ask yourself: **Is something moving from A to B?**

- **Yes**, it ends up somewhere new → **wohin?** → accusative
- **No**, it's just there (or moving around inside the same place) → **wo?** → dative

Tricky example:

- Ich laufe **in den** Park. (I run into the park — from outside to inside → accusative)
- Ich laufe **im** Park. (I run in the park — jogging around inside it → dative)

Same verb, different meaning!

## Step 4: in, an, auf — the three you'll use most

### in = inside something

- in die Küche / in der Küche (into / in the kitchen)
- in die Stadt / in der Stadt (into / in the city)

### an = touching the side, at the edge, at water

- an die Wand / an der Wand (onto / on the wall — vertical surface)
- an den See / am See (to / at the lake)
- an die Tür / an der Tür (to / at the door)

### auf = on top of a flat surface

- auf den Tisch / auf dem Tisch (onto / on the table — horizontal surface)
- auf den Boden / auf dem Boden (onto / on the floor)

Trick: **wall = an** (vertical), **table = auf** (horizontal).

## Step 5: The verb pairs (this makes it MUCH easier)

German has pairs of verbs for "put somewhere" vs "be somewhere". The verb itself tells you the case!

| Movement (wohin? → Akk.)        | Position (wo? → Dat.)         |
| ------------------------------- | ----------------------------- |
| **legen** = to lay (flat)       | **liegen** = to lie (flat)    |
| **stellen** = to stand (upright) | **stehen** = to stand        |
| **setzen** = to seat            | **sitzen** = to sit           |
| **hängen** = to hang (something) | **hängen** = to hang (be hanging) |

Examples:

- Ich **lege** das Handy auf **den** Tisch. → Das Handy **liegt** auf **dem** Tisch.
- Ich **stelle** die Flasche in **den** Kühlschrank. → Die Flasche **steht** im Kühlschrank.
- Ich **setze** das Kind auf **den** Stuhl. → Das Kind **sitzt** auf **dem** Stuhl.
- Ich **hänge** die Jacke an **den** Haken. → Die Jacke **hängt** am Haken.

Tip: **legen, stellen, setzen** are things you **do** to an object (it needs a "what") → accusative.
**liegen, stehen, sitzen** describe how something **is** → dative.

### legen vs stellen: flat vs upright

- Books lying flat, phones, keys → **legen / liegen**
- Bottles, glasses, furniture, cars (standing upright) → **stellen / stehen**

## Step 6: Contractions

| Long      | Short   | Case |
| --------- | ------- | ---- |
| in das    | **ins** | Akk. |
| in dem    | **im**  | Dat. |
| an das    | **ans** | Akk. |
| an dem    | **am**  | Dat. |
| auf das   | **aufs** | Akk. (spoken) |

Quick check: **ins** = going in (Akk.), **im** = being in (Dat.).

- Ich gehe **ins** Kino. (going to the cinema)
- Ich bin **im** Kino. (at the cinema)

## Bonus: time is always dative

When these prepositions talk about **time**, use the dative:

- **am** Montag, **im** Juli
- **vor** einer Woche (a week ago)
- **in** einer Stunde (in an hour)

## Common mistakes

| ❌ Wrong                          | ✅ Right                         | Why                             |
| -------------------------------- | ------------------------------- | ------------------------------- |
| Ich gehe im Kino.                | Ich gehe ins Kino.              | movement → accusative (ins)     |
| Ich bin ins Büro.                | Ich bin im Büro.                | location → dative (im)          |
| Das Buch liegt auf den Tisch.    | Das Buch liegt auf dem Tisch.   | liegen = location → dative      |
| Ich lege das Buch auf dem Tisch. | Ich lege das Buch auf den Tisch. | legen = movement → accusative  |
| Das Bild ist auf der Wand.       | Das Bild hängt an der Wand.     | wall = an                       |
| Ich stelle das Handy auf den Tisch. | Ich lege das Handy auf den Tisch. | phone lies flat → legen     |

## Summary

- Nine prepositions: **an, auf, hinter, in, neben, über, unter, vor, zwischen**.
- **wohin?** (movement to a new place) → **accusative**.
- **wo?** (location) → **dative**.
- Verb pairs help: **legen/stellen/setzen** → Akk., **liegen/stehen/sitzen** → Dat.
- **ins** = going in, **im** = being in.
