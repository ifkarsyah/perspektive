# Comparative and Superlative

## What is this about?

How to compare things: "bigger", "the biggest", "better than", "as big as".

## Compare with English

English has two ways to compare:

- Short words: big → big**ger** → big**gest**
- Long words: beautiful → **more** beautiful → **most** beautiful

German only has **one way** — always add the ending, no matter how long the word is:

| English                | German                  |
| ---------------------- | ----------------------- |
| small → smaller → smallest | klein → klein**er** → am klein**sten** |
| beautiful → **more** beautiful → **most** beautiful | schön → schön**er** → am schön**sten** |
| interesting → **more** interesting | interessant → interessant**er** |

So German is actually **simpler** here: never use "mehr" (more) to compare an adjective. Just add **-er**.

## The three levels

| Level         | German pattern       | Example              | English         |
| ------------- | -------------------- | -------------------- | --------------- |
| Base          | adjective            | groß                 | big             |
| Comparative   | + **-er**            | größ**er**           | bigger          |
| Superlative   | **am** + **-sten**   | **am** größ**ten**   | the biggest     |

## Why it matters

Comparing is something you do all the time: prices (cheaper, more expensive), weather (warmer, colder), preferences (I prefer..., I like ... most). And **gern → lieber → am liebsten** is how Germans say what they prefer.
