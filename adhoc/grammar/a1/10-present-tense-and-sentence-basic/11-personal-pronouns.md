# Personal Pronouns

## The idea in one sentence

Personal pronouns are the short words that replace a person or thing: **ich, du, er, sie, es, wir, ihr, sie, Sie**.

## The list

| German  | English                              |
| ------- | ------------------------------------ |
| ich     | I                                    |
| du      | you (one person, informal)           |
| er      | he                                   |
| sie     | she                                  |
| es      | it                                   |
| wir     | we                                   |
| ihr     | you (a group, informal), like "you guys" |
| sie     | they                                 |
| Sie     | you (formal, one or more people)     |

Notice: **ich** is lowercase in German (unlike English "I"). But **Sie** (formal you) is always uppercase.

## Problem 1: Two (actually three) words for "you"

English has one "you". German has three:

| Talking to...                         | Use     | Example              |
| ------------------------------------- | ------- | -------------------- |
| one friend, family member, child      | **du**  | Wie heißt du?        |
| a group of friends ("you guys")       | **ihr** | Wie heißt ihr?       |
| a stranger, boss, shop staff, official (one or many) | **Sie** | Wie heißen Sie? |

### How do I choose between du and Sie?

Think of it like first name vs. "Mr./Mrs." in English:

- If you'd call them by their **first name** → **du**.
- If you'd call them **Mr. Schmidt / Mrs. Weber** → **Sie**.

Rules of thumb:
- Friends, family, kids, people your age at a party, most young coworkers → **du**
- Doctors, shop staff, police, office, landlord, older strangers → **Sie**
- **Not sure? Use Sie.** It's never rude. Using du with a stranger can be rude.
- If someone says "Wir können uns duzen" (we can use du), switch to du.

## Problem 2: "sie" means three things

The same little word appears three times in the list. How do you know which one?

| You see          | It means           | How to tell                 |
| ---------------- | ------------------ | --------------------------- |
| sie spiel**t**   | **she** plays      | verb ends in **-t**         |
| sie spiel**en**  | **they** play      | verb ends in **-en**, lowercase sie |
| **S**ie spiel**en** | **you** (formal) play | verb ends in **-en**, uppercase Sie |

So the **verb ending** separates "she" from "they", and the **capital S** separates "they" from formal "you". (At the start of a sentence everything is capitalized anyway, so there you need context.)

## Problem 3: "it" isn't always es

In English, things are "it". In German, things have a gender (der/die/das), and the pronoun **follows the gender**:

| Noun                | Pronoun | Example                                  |
| ------------------- | ------- | ---------------------------------------- |
| **der** Tisch (table) | **er** | Der Tisch ist neu. **Er** ist schön.    |
| **die** Lampe (lamp)  | **sie** | Die Lampe ist alt. **Sie** ist kaputt. |
| **das** Buch (book)   | **es**  | Das Buch ist gut. **Es** ist spannend. |

So a German might literally say "The table is new. **He** is nice." That sounds funny in English, but it's completely normal in German. More on genders in [der/die/das](21-der-die-das.md).

## Common mistakes

| ❌ Wrong                        | ✅ Right                    | Why                               |
| ------------------------------ | -------------------------- | --------------------------------- |
| Wie heißt du? (to a police officer) | Wie heißen Sie?        | strangers/officials get Sie       |
| Ich (in the middle: "Dann Ich...") | Dann ich...             | ich is lowercase                  |
| sie heißen (meaning "you", formal) | Sie heißen              | formal Sie is always capitalized  |
| Der Stuhl ist alt. Es ist kaputt. | ... Er ist kaputt.      | der Stuhl → er                    |

## Practice

Which pronoun?

1. Talking to your best friend: "Where do you live?" → Wo wohnst ___?
2. Talking to a doctor: "Where do you live?" → Wo wohnen ___?
3. Talking to two friends: "Do you have time?" → Habt ___ Zeit?
4. "Die Tasche ist teuer. ___ ist aus Italien."
5. "Das Auto ist neu. ___ ist rot."
6. "Peter und ich lernen Deutsch." → ___ lernen Deutsch.
7. "sie wohnt" — she, they, or you (formal)?
8. "Sie wohnen" — she, they, or you (formal)?

<details>
<summary>Answers</summary>

1. du
2. Sie
3. ihr
4. Sie (die Tasche → sie, capitalized at the start of the sentence)
5. Es (das Auto → es)
6. Wir
7. she (verb ends in -t)
8. you (formal) — or "they" if it's at the start of a sentence; context decides

</details>

## Summary

- ich, du, er, sie, es, wir, ihr, sie, Sie.
- **du** = first-name people. **Sie** = Mr./Mrs. people. When unsure, **Sie**.
- **ihr** = "you guys".
- sie + **-t** = she. sie + **-en** = they. **S**ie + -en = you formal.
- Things use er / sie / es depending on der / die / das.
