# der/die/das

## The idea in one sentence

Every German noun is **masculine (der)**, **feminine (die)**, or **neuter (das)**, and you have to learn which one together with the word.

## Gender is about the word, not the thing

This is the confusing part. "Masculine" doesn't mean the thing is male. It's just the name of a group.

| Noun            | Gender     | Is it logical?                    |
| --------------- | ---------- | --------------------------------- |
| der Mann (man)  | masculine  | ✅ yes                             |
| die Frau (woman)| feminine   | ✅ yes                             |
| der Tisch (table) | masculine | 🤷 no reason                     |
| die Lampe (lamp) | feminine  | 🤷 no reason                      |
| das Mädchen (girl) | **neuter** | ❌ a girl is "it"! (explained below) |

Think of der, die, das as three **boxes** that every noun has been put into. Sometimes the box makes sense, often it doesn't.

## The golden rule

**Never learn a noun without its article.**

- ❌ Tisch = table
- ✅ **der** Tisch = table

Say it out loud as one word: "dertisch", "dielampe", "dasbuch". Your ear will start to remember what sounds right.

### Color trick

Many learners color-code their flashcards:

- 🔵 **der** = blue
- 🩷 **die** = pink
- 🩶 **das** = grey

Your brain remembers colors better than letters. Later, you'll "see" der Tisch as blue.

## Hints: endings that tell you the gender

You can't guess every noun, but many clues are reliable. Look mostly at the **end of the word**, then at what the word **means**. Some clues are nearly always right, others only usually, so learn the exceptions too.

### der (masculine)

| Clue                         | How sure      | Examples                          | Exceptions     |
| ---------------------------- | ------------- | --------------------------------- | -------------- |
| male people                  | nearly always | der Vater, der Sohn               |                |
| days, months, seasons        | nearly always | der Montag, der Mai, der Sommer   |                |
| compass points               | nearly always | der Norden, der Süden             |                |
| -ling                        | nearly always | der Frühling, der Liebling        |                |
| -ismus                       | nearly always | der Tourismus                     |                |
| person or tool made from a verb, -er | usually | der Lehrer, der Bäcker, der Fernseher | see "Careful with -er" |
| -or                          | usually       | der Motor, der Doktor             | das Labor      |
| -ist                         | usually       | der Polizist, der Tourist         |                |
| -ig, -ich                    | usually       | der Honig, der Teppich            |                |
| people ending -ant, -ent     | usually       | der Praktikant, der Student       |                |
| weather                      | usually       | der Regen, der Schnee, der Wind   | das Gewitter   |
| alcohol                      | usually       | der Wein, der Whisky              | das Bier       |
| car brands                   | usually       | der BMW, der Audi                 |                |

### die (feminine)

| Clue                          | How sure      | Examples                           | Exceptions         |
| ----------------------------- | ------------- | ---------------------------------- | ------------------ |
| female people, -in            | nearly always | die Mutter, die Lehrerin           | der Termin (a thing, not a person) |
| -ung                          | nearly always | die Zeitung, die Wohnung           | der Sprung         |
| -heit, -keit                  | nearly always | die Freiheit, die Möglichkeit      |                    |
| -schaft                       | nearly always | die Freundschaft                   |                    |
| -tät                          | nearly always | die Universität                    |                    |
| -tion, -sion                  | nearly always | die Nation, die Diskussion         |                    |
| -ei                           | nearly always | die Bäckerei, die Polizei          | das Ei             |
| -ie                           | nearly always | die Familie, die Biologie          | das Knie           |
| -ik                           | nearly always | die Musik, die Physik              | der Katholik       |
| most nouns ending in **-e**   | usually       | die Lampe, die Straße, die Tasche  | der Junge, der Name, der Käse, das Auge, das Ende |
| -ur                           | usually       | die Natur, die Kultur              | das Abitur, der Flur |
| -enz, -anz                    | usually       | die Konferenz, die Distanz         | der Tanz           |

### das (neuter)

| Clue                          | How sure      | Examples                           | Exceptions         |
| ----------------------------- | ------------- | ---------------------------------- | ------------------ |
| **-chen, -lein**              | always        | das Mädchen, das Brötchen          |                    |
| verbs used as nouns           | always        | das Essen (eating/food), das Leben (life) |             |
| starts with **Ge-**           | usually       | das Gemüse, das Getränk, das Geschenk | die Geschichte, der Geschmack |
| -nis                          | usually       | das Ergebnis, das Zeugnis          | die Erlaubnis      |
| -o                            | usually       | das Auto, das Kino, das Foto       | der Euro           |
| -ma                           | usually       | das Thema, das Klima               | die Firma          |
| -ment                         | usually       | das Dokument, das Apartment        | der Moment         |
| -um                           | usually       | das Zentrum, das Museum            | der Irrtum         |
| young beings                  | usually       | das Kind, das Baby                 |                    |
| metals                        | usually       | das Gold, das Silber               | der Stahl          |
| languages                     | usually       | das Deutsch, das Englisch          |                    |
| colors as nouns               | usually       | das Rot, das Blau                  |                    |
| English words ending -ing     | usually       | das Meeting, das Training          |                    |

**Why is das Mädchen neuter?** Because **-chen** means "little" and always makes a word neuter. Mädchen literally means "little maid". The ending wins over the meaning.

### Careful with -er

Plain **-er** is not a clue. It only points to der when it marks a person or tool made from a verb:

- lehren (to teach) → **der** Lehrer
- fernsehen (to watch TV) → **der** Fernseher

Other words ending in -er can be any gender: **die** Mutter, **die** Butter, **das** Fenster, **das** Zimmer.

## Compound nouns: look at the last word

German loves to glue nouns together. The **last word decides** the gender:

- das Haus (house) + **die Tür** (door) = **die** Haustür (front door)
- die Hand (hand) + **der Schuh** (shoe) = **der** Handschuh (glove)
- der Kaffee (coffee) + **die Maschine** = **die** Kaffeemaschine

So if you know the last word, you know the whole word. One famous exception: **der** Mittwoch (Wednesday), even though it's **die** Woche, because days are der.

## If you have to guess

Go through these in order:

1. **Compound?** Use the last word: Haustür → die Tür → **die**.
2. **Clear ending?** Look for -ung, -chen, -ist and so on, or Ge- at the start. The ending beats the meaning (**das** Mädchen).
3. **Meaning group?** A day, weather, a metal, a young being.
4. **Ends in -e?** Guess **die**.
5. **One syllable?** Guess **der** (der Tisch, der Stuhl). This is only a weak tendency: **das** Buch, **die** Tür.

## Common mistakes

| ❌ Wrong          | ✅ Right          | Why                                |
| ---------------- | ---------------- | ---------------------------------- |
| die Mädchen (one girl) | das Mädchen | -chen is always das               |
| der Zeitung      | die Zeitung      | -ung is almost always die          |
| das Haustür      | die Haustür      | last word (die Tür) decides        |
| learning "Auto = car" | "das Auto = car" | always learn the article       |

## Summary

- Three genders: **der** (masculine), **die** (feminine), **das** (neuter).
- Gender is only partly predictable. **Always learn the article with the noun.**
- Endings help: -ung/-heit/-keit/-e → die, -chen → das, days/months → der.
- Compound nouns: the **last** word decides.
