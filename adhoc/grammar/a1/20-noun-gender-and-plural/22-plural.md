# Plural

## The idea in one sentence

When there's more than one, the article is **always die**, but the noun itself can change in **several different ways**.

## Compare with English

English mostly adds **-s**: one book → two books. A few words are irregular: one man → two **men**, one child → two **children**, one mouse → two **mice**.

In German, those "irregular" ways are actually normal. There are about 5 common patterns, and **-s** is the rarest one.

## The easy part: the article

No matter the gender, plural is always **die**:

| Singular        | Plural            |
| --------------- | ----------------- |
| **der** Tisch   | **die** Tische    |
| **die** Lampe   | **die** Lampen    |
| **das** Buch    | **die** Bücher    |

## The hard part: the noun ending

Here are the patterns. The two dots on a vowel (ä, ö, ü) are called an **umlaut**.

| Pattern            | Singular       | Plural          | English (similar idea)    |
| ------------------ | -------------- | --------------- | ------------------------- |
| add **-e**         | der Tag        | die Tag**e**    |                           |
| umlaut + **-e**    | der Stuhl      | die St**ü**hl**e** |                        |
| add **-er**        | das Kind       | die Kind**er**  | child → child**ren**      |
| umlaut + **-er**   | das Buch       | die B**ü**ch**er** |                        |
| add **-n / -en**   | die Lampe      | die Lampe**n**  | ox → ox**en**             |
| add **-s**         | das Auto       | die Auto**s**   | car → car**s**            |
| nothing changes    | der Lehrer     | die Lehrer      | sheep → sheep             |
| only umlaut        | der Apfel      | die **Ä**pfel   | man → m**e**n             |

## Rules of thumb (they work most of the time)

You don't need to guess blindly. These hints work well:

1. **Feminine nouns → -n or -en.** This is the most reliable rule.
   - die Frau → die Frau**en**, die Zeitung → die Zeitung**en**, die Tasche → die Tasche**n**
2. **Female jobs ending in -in → -nen.**
   - die Lehrerin → die Lehrerin**nen**
3. **Masculine or neuter ending in -er, -el, -en → no ending** (sometimes an umlaut).
   - der Lehrer → die Lehrer, der Wagen → die Wagen, der Vater → die V**ä**ter
4. **Short masculine nouns → -e**, often with umlaut.
   - der Tag → die Tage, der Zug → die Z**ü**ge
5. **Short neuter nouns → -er**, with umlaut if possible.
   - das Kind → die Kinder, das Haus → die H**ä**user
6. **Foreign words and words ending in -a, -i, -o, -u → -s.**
   - das Handy → die Handys, das Kino → die Kinos, das Café → die Cafés

## "A" has no plural

English: a book → books (no "a").
German is the same: **ein** Buch → Bücher (no "ein").

- Ich habe **ein** Kind. (I have a child.)
- Ich habe **zwei** Kinder. (I have two children.)
- Ich kaufe Äpfel. (I buy apples.)

## How to learn plurals

Same as gender: **learn them together with the noun**. Your flashcard should have three parts:

> **der** Stuhl, **die** Stühle — chair

Dictionaries often write it in short form: **Stuhl, der, -¨e**. That means: masculine, plural adds umlaut + e.

## Common mistakes

| ❌ Wrong           | ✅ Right          | Why                                    |
| ----------------- | ---------------- | -------------------------------------- |
| die Kinds         | die Kinder       | -s is rare, don't add it by default    |
| der Bücher        | die Bücher       | plural is always die                   |
| die Frauen**s**   | die Frauen       | only one plural ending                 |
| ein Bücher        | Bücher           | no "ein" in plural                     |

## Practice

Make the plural.

1. die Wohnung
2. das Auto
3. der Lehrer
4. die Freundin
5. das Haus
6. die Straße
7. der Tag
8. das Kino

1. die Wohnungen (feminine → -en)
2. die Autos (ends in -o → -s)
3. die Lehrer (ends in -er → no change)
4. die Freundinnen (-in → -nen)
5. die Häuser (short neuter → umlaut + -er)
6. die Straßen (feminine → -n)
7. die Tage (short masculine → -e)
8. die Kinos (ends in -o → -s)

## Summary

- Plural article is **always die**.
- 5 main patterns: -e, -er, -(e)n, -s, no change (often with umlaut).
- Feminine → usually **-(e)n**. Ends in -er/-el/-en → usually **no change**.
- Learn every noun as **article + singular + plural**.
