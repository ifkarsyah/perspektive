# ein/eine/einen

## The idea in one sentence

**ein / eine** means "a" or "an", and the masculine form changes from **ein** to **einen** when it's the object of the sentence.

## Step 1: "a" depends on gender

| Gender     | "the" | "a"      | Example                 |
| ---------- | ----- | -------- | ----------------------- |
| masculine  | der   | **ein**  | ein Tisch (a table)     |
| feminine   | die   | **eine** | eine Lampe (a lamp)     |
| neuter     | das   | **ein**  | ein Buch (a book)       |
| plural     | die   | —        | Bücher (books)          |

Easy trick: feminine **die** ends in **-e**, so feminine **eine** also ends in **-e**.

## Step 2: Masculine changes in the accusative

Remember from [der and den](31-der-den.md): only masculine changes. Just like **der → den**, we get **ein → einen**.

| Case        | masc.      | fem.   | neut. |
| ----------- | ---------- | ------ | ----- |
| Nominative  | ein        | eine   | ein   |
| Accusative  | **einen**  | eine   | ein   |

Notice the pattern: **den** and **ein**en both end in **-n**. The accusative masculine "n" is the thing to remember.

## Worked examples

### Nominative (subject or "this is...")

- Das ist **ein** Tisch. (That is a table.)
- Hier ist **eine** Bäckerei. (Here is a bakery.)
- **Ein** Mann kommt. (A man is coming.)

After **sein** (to be), it's always nominative. "That is a table" — the table isn't receiving any action.

### Accusative (object)

- Ich kaufe **einen** Tisch. (I buy a table.)
- Ich suche **eine** Wohnung. (I'm looking for an apartment.)
- Ich habe **ein** Auto. (I have a car.)

### Building one step by step

"I need a pen." (der Stift = pen)

1. Who needs? ich → nominative, no article issue.
2. What is needed? the pen → **accusative**.
3. Gender? **der** Stift → masculine.
4. Masculine accusative "a" → **einen**.
5. **Ich brauche einen Stift.**

## Verbs that (almost) always have an accusative object

These verbs need something to act on, so the thing after them is accusative:

| Verb     | Example                         |
| -------- | ------------------------------- |
| haben    | Ich habe einen Bruder.          |
| kaufen   | Ich kaufe einen Apfel.          |
| brauchen | Ich brauche einen Stift.        |
| suchen   | Ich suche einen Job.            |
| sehen    | Ich sehe einen Hund.            |
| essen    | Ich esse einen Apfel.           |
| trinken  | Ich trinke einen Kaffee.        |
| nehmen   | Ich nehme einen Tee.            |
| möchten  | Ich möchte einen Saft.          |

### es gibt + accusative

**Es gibt** means "there is / there are". It always takes accusative:

- Es gibt **einen** Park hier. (There is a park here.)
- Es gibt **eine** Bäckerei. (There is a bakery.)

## Common mistakes

| ❌ Wrong                    | ✅ Right                    | Why                               |
| -------------------------- | -------------------------- | --------------------------------- |
| Ich habe ein Bruder.       | Ich habe einen Bruder.     | der Bruder, object → einen        |
| Das ist einen Tisch.       | Das ist ein Tisch.         | after sein → nominative           |
| Ich habe einen Auto.       | Ich habe ein Auto.         | das Auto doesn't change           |
| Ich kaufe einen Lampe.     | Ich kaufe eine Lampe.      | die Lampe → eine (never changes)  |
| Ich habe eine Bücher.      | Ich habe Bücher.           | no "a" in plural                  |

## Practice

1. Ich habe ___ Hund. (der Hund)
2. Das ist ___ Katze. (die Katze)
3. Wir kaufen ___ Auto. (das Auto)
4. Ich brauche ___ Computer. (der Computer)
5. Das ist ___ Computer. (der Computer)
6. Es gibt ___ Supermarkt hier. (der Supermarkt)
7. Sie trinkt ___ Tee. (der Tee)
8. Ich suche ___ Wohnung. (die Wohnung)

<summary>Answers</summary>

1. einen (object, masculine)
2. eine (after sein, feminine)
3. ein (neuter doesn't change)
4. einen (object, masculine)
5. ein (after sein → nominative)
6. einen (es gibt + accusative)
7. einen (object, masculine)
8. eine (feminine never changes)

## Summary

- **ein** (masc./neut.), **eine** (fem.), nothing in plural.
- Masculine object → **einen**. Nothing else changes.
- After **sein** ("this is a...") → nominative, so no change.
- **es gibt** → always accusative.
