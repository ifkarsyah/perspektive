# kein

## The idea in one sentence

**kein** means "no", "not a", or "not any", and it takes **the same endings as ein**.

## Think of it as "k + ein"

Just put a **k** in front of ein:

- **ein** Hund (a dog) → **kein** Hund (no dog)
- **eine** Katze (a cat) → **keine** Katze (no cat)
- **einen** Hund → **keinen** Hund

It's literally "k-ein". That's how you remember the endings: they're the ein endings.

## The table

| Case        | masc.       | fem.     | neut.   | plural    |
| ----------- | ----------- | -------- | ------- | --------- |
| Nominative  | kein        | keine    | kein    | keine     |
| Accusative  | **keinen**  | keine    | kein    | keine     |

Like mein, kein has a plural (keine), because "no books" makes sense.

## How English says it

English has several ways to say this. German uses **kein** for all of them:

| English                       | German                        |
| ----------------------------- | ----------------------------- |
| I **don't have a** dog.       | Ich habe **keinen** Hund.     |
| I have **no** time.           | Ich habe **keine** Zeit.      |
| That's **not a** dog.         | Das ist **kein** Hund.        |
| We **don't have any** children. | Wir haben **keine** Kinder. |
| There's **no** milk.          | Es gibt **keine** Milch.      |

Notice: English often uses "don't" + "a". German just uses kein. No "nicht" needed.

## When do I use kein?

Use kein when the noun would have **ein** or **no article** in the positive sentence:

| Positive                | Negative                  |
| ----------------------- | ------------------------- |
| Ich habe **ein** Auto.  | Ich habe **kein** Auto.   |
| Ich habe Zeit. (no article) | Ich habe **keine** Zeit. |
| Ich trinke Kaffee. (no article) | Ich trinke **keinen** Kaffee. |

For everything else, use **nicht**. The full rule is in [nicht vs kein](41-nicht-vs-kein.md).

## Common mistakes

| ❌ Wrong                     | ✅ Right                   | Why                              |
| --------------------------- | ------------------------- | -------------------------------- |
| Ich habe nicht ein Auto.    | Ich habe kein Auto.       | "nicht ein" → kein               |
| Ich habe kein Bruder.       | Ich habe keinen Bruder.   | der Bruder, object → keinen      |
| Ich habe nicht Zeit.        | Ich habe keine Zeit.      | noun without article → kein      |
| Das ist keinen Hund.        | Das ist kein Hund.        | after sein → nominative          |

## Practice

Make it negative with kein.

1. Ich habe einen Bruder.
2. Das ist eine gute Idee.
3. Wir haben Kinder.
4. Er trinkt Bier. (das Bier)
5. Ich habe Hunger. (der Hunger)
6. Es gibt einen Park hier.

<details>
<summary>Answers</summary>

1. Ich habe keinen Bruder.
2. Das ist keine gute Idee.
3. Wir haben keine Kinder.
4. Er trinkt kein Bier.
5. Ich habe keinen Hunger.
6. Es gibt keinen Park hier.

</details>

## Summary

- kein = **k + ein**, same endings, plus plural keine.
- Use it instead of "nicht ein" and for nouns without an article.
- Masculine object → **keinen**.
